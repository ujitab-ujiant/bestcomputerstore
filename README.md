## 📌 Latar Belakang Project

**BestComputer** merupakan aplikasi web manajemen toko komputer yang
awal mulanya dikembangkan sebagai bagian dari kegiatan
**Magang / Kerja Praktik (KP)**.

Setelah kegiatan magang selesai, project ini kemudian
mengalami **pengembangan lanjutan (improvement)** dan
penyesuaian agar sesuai dengan kebutuhan
**tugas perkuliahan**.

Project ini digunakan sebagai media pembelajaran dalam
menerapkan konsep pengembangan sistem informasi berbasis web
menggunakan framework Laravel.

Keaslian Project ini dapat dibuktikan dengan Laporan Kerja Praktik yang telah dibuat sebelumnya jika diminta
---


## 🛠 Tech Stack

- Laravel 11
- PHP 8+
- MySQL
- Tailwind CSS, Bootstrap
- Native Laravel Authentication
- Vite

---

## ✨ Fitur Aplikasi

- Autentikasi pengguna
- Manajemen data produk komputer
- Manajemen transaksi penjualan dan layanan
- Dashboard admin
- Pengelolaan pengguna
- Laporan penjualan *(pengembangan)*
